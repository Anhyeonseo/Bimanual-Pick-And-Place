# media

메인 README의 Demo 섹션이 참조하는 실제 파일을 여기 둔다.

- `demo-thumbnail.jpg` — 성공 실행 영상의 썸네일 이미지. 영상 자체는 여기 두지
  않고 **Google Drive에 올린 뒤 그 공유 링크를 README에 붙여넣는다**(썸네일을
  클릭하면 Drive로 이동). GitHub는 영상 자동 재생이나 임베드를 지원하지 않아서
  이 방식이 가장 간단하다.
- `pick-and-place.jpg` — 성공 장면 사진. 이건 로컬 파일 그대로 README에 표시된다.

파일을 넣고 Google Drive 링크를 준비했으면 `README.md`의 `## Demo` 섹션
주석을 해제하고, `구글드라이브_공유링크를_여기에_붙여넣기` 부분만 실제 링크로
바꾸면 된다. Drive 공유 설정은 "링크가 있는 모든 사용자"로 열어둬야 다른
사람이 볼 수 있다.
